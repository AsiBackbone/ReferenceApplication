# API Reference

This section is the generated .NET API reference for the AsiBackbone Reference Application.

DocFX builds the type and member pages from the production projects under `src/`. Test projects and build artifacts are not part of the API reference. Use the API navigation and search to inspect the public types emitted by the current documentation build.

## Authority and scope

The generated API reference documents the **Reference Application's own code**: the NCAT-generated host projects and the AsiBackbone integration code added on top of them, including the sample governance rules.

It does not re-document the packages the host consumes. For those contracts, use the authoritative references:

- [AsiBackbone API reference](https://asibackbone.github.io/AsiBackbone/api-reference.html)
- [NCAT API reference](https://asibackbone.github.io/NetCoreApplicationTemplate/api/)

For the order in which the code was added and why, see the [Integration Walkthrough](../walkthrough/index.md). For architecture education, use [AsiBackbone Learning](https://asibackbone.github.io/Learning/).

## Version context

This landing page is intentionally stable so the published `/api/` URL remains navigable while the generated type and member pages change with the source tree.
